## Code

Inline code like `bun run build` stays plain. Add a language suffix to highlight it: `const total = price * quantity{:ts}`.

A block with a title and highlighted lines (`title="…" {3-4}`):

```ts title="lib/position.ts" {3-4}
type Position = { symbol: string; entry: number; size: number };

export const pnl = (position: Position, price: number) =>
  (price - position.entry) * position.size;

export const pnlPercent = (position: Position, price: number) => {
  const change = (price - position.entry) / position.entry;
  return Math.round(change * 10000) / 100;
};
```

Line numbers (`showLineNumbers`):

```python showLineNumbers
import pandas as pd

def moving_average(prices: pd.Series, window: int = 20) -> pd.Series:
    """Simple moving average over the given window."""
    return prices.rolling(window=window).mean()

df = pd.read_csv("prices.csv", parse_dates=["date"])
df["sma_20"] = moving_average(df["close"])
print(df.tail())
```
